Floating menu

Prompt templates

Used by the floating menu and by + → Use a prompt in Yavar. Placeholders are filled in when a prompt runs: {{selection}}, {{page}}, {{clipboard}}, {{url}}, {{title}}, {{repo}}. In menu pins a template to the floating menu; the rest sit behind its ⋯.

GitHub access

Raises the rate limit from 60 to 5,000 requests an hour and lets Yavar read your private repos. A read-only token is enough (classic public_repo, or fine-grained "Contents: read"). Stored on this device only, never synced or exported.

Video research

Video research pulls transcripts of the top YouTube results from your local ytx server. Start it with uv run uvicorn ytx_api.main:app --port 8722 (or set it to start at login; see the README).
